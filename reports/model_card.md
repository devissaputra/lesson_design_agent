# Analytic system card

## System

Lesson Design Agent

## Purpose

Deterministic lesson planning baseline for Bloom level inference, time allocation, and accessibility checks.

## Current maturity

Working research prototype. The bundled example checks the software path with synthetic inputs. It does not establish validity for real learners, instructors, courses, or workplaces.

## Inputs

See `../data/README.md` for the current synthetic schema and the documentation expected before real data are connected.

## Outputs

The current code produces a Bloom level, a four stage time allocation, and an accessibility checklist. These outputs are research signals and should be interpreted with the educational context that produced them.

## Evidence needed before real use

Have learning designers review the same briefs and rate objective alignment, activity fit, time realism, accessibility, and revision effort. Compare the baseline with stronger drafting methods without hiding human edits.

## Main limitation

The baseline does not write lesson content, align assessments, or understand subject matter. Its output is a planning scaffold that still requires a qualified learning designer.

## Human oversight

A person must review any output before it can affect a learner, instructor, applicant, or employee.
