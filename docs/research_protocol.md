# Research protocol

## Project

Lesson Design Agent

## Questions

1. Can structured design constraints improve consistency of lesson plans generated by AI?
2. How can pedagogical rationale remain visible to the designer?
3. Which accessibility and assessment checks should be mandatory before export?

## Baseline methods

- Bloom verb inference
- four stage lesson sequence
- exact time budget allocation
- guided practice structure
- accessibility checklist

## Evidence to collect

Start from the current transparent baseline and record every transformation needed to produce a Bloom level, a four stage time allocation, and an accessibility checklist. Keep a clear boundary between synthetic demonstration data and any future empirical dataset.

## Validation

Have learning designers review the same briefs and rate objective alignment, activity fit, time realism, accessibility, and revision effort. Compare the baseline with stronger drafting methods without hiding human edits.

## What counts as a useful result

A stronger version should compare these deterministic drafts with expert designed lessons and with a language model under the same constraints. Alignment, feasibility, accessibility, and designer editing effort should be rated separately.

## Threats to validity

Verb based Bloom inference is shallow, lesson timing depends on learner context, and accessibility requirements vary by medium, audience, and institutional policy.
